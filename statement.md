# Mini Banking System

## Problem Statement

The Mini Banking System is a command-line based Python application designed to perform basic banking operations. It allows users to create an account, log in  using a PIN, deposit money, withdraw money, and transfer money between accounts.

The system stores account information  and provides input checking to prevent invalid data. PINs are stored in hashed form to provide  security.

## Objectives

- To create and manage accounts.
- To provide  user login using a PIN.
- To perform deposit and withdrawal .
- To transfer money between different accounts.
- To validate user inputs and handle errors.
- To store account data for future use.

## Scope of the Project

The project focuses on providing  banking operations through a command-line . It covers account creation, login, balance checking, deposits, withdrawals, money transfers, transaction history, and data storage in json.

The project is for a initial stage banking simulation and does not include real banking services, online payments, or connections to actual bank accounts.

## Target Users

The system is designed for users who want to perform basic banking operations through a simple command-line . It can also be used by students and beginners to understand how banking operations, authentication, data storage, and transaction processing can be done using Python.

## High-end Features


- Set a 4-digit PIN
- Secure PIN storage using SHA-256 hashing
- User login and authentication
- Transfer money between different accounts
- View transaction history of accounts
- using json to store data
- Input validation and error correction
