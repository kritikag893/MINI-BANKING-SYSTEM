# Mini Banking System

## Problem Statement

The Mini Banking System is a command-line based Python application designed to perform basic banking operations. It allows users to create an account, log in  using a PIN, deposit money, withdraw money, and transfer money between accounts.

The system stores account information  and provides input validation to prevent invalid operations. PINs are stored in hashed form to provide  security.

## Objectives

- To create and manage basic bank accounts.
- To provide secure user login using a PIN.
- To perform deposit and withdrawal operations.
- To transfer money between accounts.
- To validate user inputs and handle errors.
- To store account data for future use.

## Scope of the Project

The project focuses on providing basic banking operations through a command-line interface. It covers account creation, login, balance checking, deposits, withdrawals, money transfers, transaction history, and data storage in json.

The project is intended as a small-scale banking simulation and does not include real banking services, online payments, or connections to actual bank accounts.

## Target Users

The system is designed for users who want to perform basic banking operations through a simple command-line interface. It can also be used by students and beginners to understand how banking operations, authentication, data storage, and transaction processing can be implemented using Python.

## High-Level Features


- Set a 4-digit PIN
- Secure PIN storage using SHA-256 hashing
- User login and authentication
- Transfer money between accounts
- View transaction history
- Store account data using JSON
- Input validation and error handling
